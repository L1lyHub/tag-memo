# Tag-Memo

タグを選んでメモを書くだけで、日時つきの記録を残せるアプリです。記録はカレンダーやグラフで振り返れます。ブラウザで開くだけで使え、アカウントの登録は要りません。

https://l1lyhub.github.io/tag-memo/

## できること

- 記録: 日付・時刻、タグ（いくつでも選べる）、メモを記録する。タグかメモのどちらかがあれば記録できる。タグはよく使う順に並ぶ
- 一覧: すべての記録を新しい順に表示する。タグや「タグなし」で絞り込める。記録の編集・削除もここからできる
- カレンダー: 記録のある日に件数を表示し、件数が多い日ほど色が濃くなる。土曜・日曜・祝日は色分けする。日付をタップすると、その日の記録が出る
- グラフ: 12 か月分の月別の記録数と、時間帯（朝・昼・夜・深夜）ごとの割合。前後の期間に移動できる
- タグの管理: タグの追加（20 文字まで）と削除。記録で使っているタグを削除すると、その記録からも外れる
- バックアップ: 記録とタグを JSON ファイルに書き出し、読み込んで戻せる。設定画面に前回のバックアップの日を表示し、7 日以上たつと赤字で知らせる
- ライト／ダーク表示。端末の設定に合わせることもできる
- 一度開いたあとは、オフラインでも開ける

## スマホで使う

- iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
- Android（Chrome）: メニュー →「ホーム画面に追加」（または「アプリをインストール」）

ホーム画面から開くと、アドレスバーのない画面で開きます。アプリの中身が更新されたときは、追加し直さなくても、アプリを終了して開き直せば新しくなります。

## 記録の保存とバックアップ

記録は、使っている端末のブラウザの中だけに保存されます。サーバーには送らないので、ほかの端末とは同期しません。

次のときは記録が消えます。先にエクスポートしておいてください。

- ホーム画面からアプリを削除したとき
- Safari のまま使っていて、Safari の履歴と Web サイトデータを消去したとき

iPhone では、Safari で開いたときと、ホーム画面に追加したアプリとで記録が別々になります。Safari で付けていた記録をアプリに移すときも、エクスポートとインポートを使ってください。

### バックアップする

1. 設定タブの「JSONエクスポート」をタップ
2. iPhone では共有シートで「"ファイル"に保存」を選び、保存先に「iCloud Drive」などを選んで保存（共有シートが出ない端末では、ファイルがダウンロードされる）

### 復元する

- 「JSONインポート」: ファイルの記録を、今ある記録に追加する
- 「JSONインポート（完全置換）」: 今ある記録とタグをすべて消して、ファイルの中身に置き換える

今の記録が残っている状態で「JSONインポート」を使うと、同じ記録が二重になります。その場合は「完全置換」を使ってください。
